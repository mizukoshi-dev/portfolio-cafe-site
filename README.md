# RISE CAFE 架空のカフェ紹介サイト

HTML/CSSの基礎から応用（レスポンシブ、パララックス効果）を習得するために作成した、カフェの紹介サイトです。

## 概要
1枚のHTMLとCSSで構成されたシングルページのデザインです。
清潔感と温かみのあるカフェをイメージし、PCとスマートフォンの両方で快適に閲覧できるコーディングを行いました。

## 開発で意識したこと
- **レスポンシブデザイン（メディアクエリ）**:
  画面幅1050pxを境界に、PCとスマホで最適なレイアウトに切り替わるように実装しました（FlexboxやGridを使用）。
- **ユーザー体験（UX）**:
  スクロール時のパララックス（視差効果）や、ボタンのhoverアニメーション、スムーススクロールなどを取り入れ、リッチな閲覧体験を目指しました。
- **アクセシビリティ**:
  フォーム部品（input, checkbox等）に適切なlabelを紐付け、使いやすさを考慮したマークアップを行っています。

## 構成
- `index.html`: 構造の定義
- `css/reset.css`: ブラウザのデフォルトスタイル解消
- `css/style.css`: デザイン・アニメーションの実装
- `images/`: サイト内で使用している静止画

## リファクタリング予定項目
- **コードのクリーンアップ**: 未使用タグの整理や、CSSの共通化による冗長な記述の削除。
- **コメントアウトの追加**: 構造を誰が見ても理解できるよう、各セクションの区切りを明確にする。
- **BEM設計の導入**: クラス名の命名規則を整理し、メンテナンス性を高める。

## 今後について
現在はJavaで学んだバックエンドのロジックと、このHTML/CSSのスキルを組み合わせ、ReactやTypeScriptを用いたモダンなフロントエンド開発の学習を進めています。
